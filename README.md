# CTM financial model generator

This repository contains a Python workbook generator for the CTM financial analysis model.

What it does
- creates a workbook with the same structure and logic as the model in the reference CSV
- keeps the CTM-specific sections and annual layout (2021–2026)
- preserves formula-driven Excel cells and ratio-style layout
- exports a data reference file for quick validation

How to generate the workbook locally

1. Install openpyxl:
   python -m pip install openpyxl
2. Run:
   python generate_ctm_model.py
3. Output:
   - Modèle Analyse CTM 2021-2025.xlsx
   - CTM_Reference_Model_Data.csv

Important note
- This environment cannot directly upload a binary .xlsx file via the GitHub API, so the workbook is generated by script instead.
- The macro-free workbook structure is intentionally aligned to the CTM reference data already available in the repository and to the financial model logic described in the reference CSV.
- Source values should still be validated against official CTM annual reports / AMMC / Bourse de Casablanca before publication.
